# IANA media type registrations

Registration templates for the media types in
[package spec §12.1](../../spec/moca-package-spec.md#121-media-types), in the
form [RFC 6838 §5.6](https://www.rfc-editor.org/rfc/rfc6838#section-5.6) asks
for. They are submitted to IANA through its
[media types form](https://www.iana.org/form/media-types) once the
specification version they cite is tagged.

| Media type | File | Template |
| --- | --- | --- |
| `application/vnd.openmoca.package+zip` | `.moca` package archive | [package](application-vnd.openmoca.package+zip.md) |
| `application/vnd.openmoca.envelope+zip` | `.moca.enc` envelope | [envelope](application-vnd.openmoca.envelope+zip.md) |
| `application/vnd.openmoca.index+zip` | `.moca.idx.zip` sidecar index | [sidecar index](application-vnd.openmoca.index+zip.md) |

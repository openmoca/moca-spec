# Microsoft Agent Framework - Part#7: Events, Human-in-the-Loop & Resilient workflows using Checkpoint

[Watch on YouTube](https://www.youtube.com/watch?v=Nnf6E1fmPBs) · [Karthikeyan Vijayakumar](https://www.youtube.com/channel/UCUABQE89pVvAHEgCRYWrGyg) · published 2026-01-29 · 27:56

## Description

In this comprehensive guide, we explore the advanced features of the Microsoft Agent Framework to help you build production-ready AI orchestrations.

We start by breaking down Workflow Events, an event-based system that allows developers to monitor, debug, and dynamically control execution. You'll learn how to categorize these into lifecycle, super-step, and executor events for maximum observability.

Next, we tackle Human-in-the-Loop (HITL). Using the request\_info event, we demonstrate how to pause a workflow for manual approval (e.g., a refund request over $100) and resume it once external feedback is received.

Finally, we dive into Checkpoints. Discover how to save the state of long-running workflows to a file or database, allowing you to "rehydrate" and resume execution even after a system crash or intentional pause.

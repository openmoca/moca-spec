# Handling a refund request

1. Find the order and check the delivery date in the order system.
2. Check the [refund window](../returns/refund-window.md) and whether the item is [final sale](../returns/final-sale-items.md).
3. Approve the return in the order system; the customer gets a label by email.
4. Refund when the warehouse marks the item as received.

# Traiter une demande de remboursement

1. Retrouvez la commande et vérifiez la date de livraison dans le système de commandes.
2. Vérifiez le [délai de remboursement](../returns/refund-window.md) et si l'article est en [vente finale](../returns/final-sale-items.md).
3. Approuvez le retour dans le système de commandes ; le client reçoit une étiquette par e-mail.
4. Remboursez quand l'entrepôt indique l'article comme reçu.

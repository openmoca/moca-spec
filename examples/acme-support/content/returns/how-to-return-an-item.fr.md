# Retourner un article

1. Vérifiez que l'article est dans le [délai de remboursement](refund-window.md).
2. Ouvrez la commande dans votre compte et choisissez **Retourner**.
3. Imprimez l'étiquette et emballez l'article dans son emballage d'origine.
4. Déposez le colis dans n'importe quel bureau de poste.
